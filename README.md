# nullpointer-log 技術ポートフォリオ

組み込みソフトウェアの実務経験と、Computer Visionなどの個人開発を紹介するHugoサイトです。

- 公開サイト：https://nullpointer-log.github.io/
- Hugo Extended：0.146.5
- テーマ：PaperMod（テーマ本体を直接編集せず、layoutsと拡張CSSで調整）

## ソース構成

| 場所 | 内容 |
| --- | --- |
| `config.toml` | サイト設定・メニュー |
| `content/` | 経験、プロジェクト、記事、問い合わせなどの本文 |
| `layouts/` | トップページなどのテンプレート上書き |
| `assets/css/extended/` | 表示調整 |
| `static/` | 公開用の静的ファイル |
| `.github/workflows/hugo.yml` | GitHub Pagesへのビルド・デプロイ |

既存記事のURLを維持します。リポジトリ直下に残る生成HTMLではなく、Hugoソースを編集してください。

## ローカル確認

Hugo Extended 0.146.5とテーマのサブモジュールを利用します。

```powershell
git submodule update --init --recursive
hugo server --bind 127.0.0.1
```

ブラウザーで `http://127.0.0.1:1313/` を開きます。生成物をソースと混ぜないビルド例：

```powershell
hugo --minify --destination "$env:TEMP/nullpointer-log-preview"
```

GitHub ActionsもHugo Extended 0.146.5を使用し、mainへのPushまたは手動実行でデプロイします。コミットだけでは公開されません。

## Hand Rehabilitation Trackerの記載

紹介ページ：`content/projects/hand-rehabilitation-tracker/index.md`

2026年10月18日にアプリのローカルソースとデモ動画（約67秒）を照合した説明です。

- 指・手首・回旋の3モードを選択し、画像とグラフを一画面に表示します。
- 指は薬指3関節の角度と合計最小値、手首・回旋は両方向の極値と動作回数を記録します。
- PDFはA4・3ページで、モードごとに結果・極値画像・履歴を掲載します。
- 履歴は過去最大10回。今回を含む場合は最大11行で、完了回数5回以上の測定が対象です。
- メールは利用者の操作とGoogle認証により送信し、短い本文とPDF1件を使用します。画像・CSVは個別添付しません。PDF内には画像と測定値が含まれます。
- アプリのソースはPrivateで管理しています。一般閲覧者向けのソースコードリンクは設けていません。

合成データを用いた自動テストは処理の確認です。臨床的な測定精度、再現性、医療上の有効性の検証とは区別します。本アプリは技術検証目的の試作であり、診断・治療を目的としません。

トップページのサムネイルは動画冒頭のタイトル画面だけを使用しています。手の撮影画像・実測値・メール画面は含みません。画像のリンク先はプロジェクト詳細ページです。

## 動画の公開前確認

デモ動画原本はこのリポジトリに追加していません。確認した映像には手の撮影画像、測定日時・角度・回数・過去履歴が含まれます。本人の公開許可、全フレーム・音声・メタデータの確認を済ませ、必要に応じてマスクまたは合成データへ置き換えてから公開用ファイルを追加します。

埋め込み時は「デモ動画（約1分）」の見出しと説明を付け、HTML5 videoに`controls`、`preload="metadata"`、幅100%・高さautoを設定します。公開用動画を追加するまでは、存在しない動画URLや再生枠を掲載しません。
