組み込みソフトウェアの設計・実装・評価・不具合解析に携わってきました。実務経験と個人開発・技術検証を分けて紹介します。

## 実務経験

### 組み込みソフトウェア開発

| 分野 | 主な業務内容 | 使用技術・環境 |
| --- | --- | --- |
| 設計・実装 | 組み込みソフトウェアの設計・実装 | C / C++ |
| OS環境での開発・評価 | Embedded Linux・RTOSを使用したソフトウェアの開発・評価 | Embedded Linux / RTOS |
| マルチコア・通信 | マルチコアプロセッサ、プロセッサ間通信に関するソフトウェア開発 | マルチコア / IPC |
| 評価ボードの立ち上げ | ハードウェア評価ボードの立ち上げ・動作検証 | 評価ボード |
| 不具合解析・性能評価 | ソースコード・ログの調査、不具合の原因分析、ソフトウェアの性能評価 | ソースコード解析 / ログ解析 / デバッグ |

### アプリケーション開発

Python・Windowsアプリケーションによる評価自動化、データ収集・可視化ツールの設計・実装を経験しています。複数カメラの映像表示・記録、OpenGLによるリアルタイム描画にも携わってきました。

### 画像処理・Computer Vision

| 分野 | 主な業務内容 | 使用技術・環境 |
| --- | --- | --- |
| 物体検出 | 技術選定、学習データの整備・アノテーション、追加学習、推論・結果確認UIの実装 | Python / YOLO / OpenCV |
| カメラ接続 | カメラ接続環境の立ち上げ、周辺デバイス設定、画像出力の検証、不具合切り分け | Jetson / Linux / I2C / SerDes |

### センサー連携・通信

バイタルセンシングにおいて、BLE接続のセンサーから心拍関連データを取得する処理を経験しています。また、センサー制御やシリアル・Ethernet通信機能の実装に携わってきました。

具体的な開発環境や担当工程については、守秘義務に配慮し、公開可能な範囲で個別に説明します。
